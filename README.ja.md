# SensorLens

SwitchBot の温度・湿度・CO2 を macOS のメニューバーに表示するアプリ。

[`sensor-lens`](../sensor-lens) CLI のメニューバー・フロントエンドで、CLI は
アプリ内に同梱されます。認証情報の保持・SwitchBot API との通信・データベースの
所有はすべて CLI 側で、本アプリはそれを表示し、**稼働中は収集も担当**します。

![メニューバー](docs/menubar.png)

## 必要なもの

- macOS 14+、Apple Silicon
- SwitchBot ハブと、アプリで発行したトークン・シークレット
  （プロフィール → 設定 → **アプリバージョン**を10回タップ → 開発者向けオプション）

## インストール

```bash
make build-app        # -> dist/SensorLens.app (署名済み、CLI 同梱)
open dist/SensorLens.app
```

トークンとシークレットを `config.toml` に記入し（場所は About タブに表示されます）、
**Refresh** を押してください。あとはアカウントから自動検出されます。

## 家中を収集して、2つだけ表示する

**メニューバー**には選んだ最大3件を表示します。単位は**デバイス × metric** なので、
あるセンサーからは CO2 だけ、別のセンサーからは温度だけ、という選び方ができます。
並び順はドラッグで変更できます。一番左が、意識せず目に入る位置です。
クリックすると、その同じ項目が**直近6時間の推移**とトレンド矢印付きで開きます。

何を*収集*するかはこれとは別の、もっと広い選択で、CLI の `config.toml` が持ちます。
8台収集して2つをバーに出す、という使い方が想定です。家中を収集することは履歴を
完全にするために意味がありますが、メニューバーのクリックで15枚のカードを読みたい
人はいません。収集中の全センサーは History ウィンドウで見られます。

## 誰が収集するか

アプリは稼働中、CLI の `now --if-stale` を定期実行して収集します。これは
**保存済みの値が間隔より古くなった時だけ**ポーリングします。24時間動くデーモンに対して
API 消費が約半分になるのは、実際にマシンの前にいる間だけ収集するからです。

**Collection → Open SensorLens at login** も同じ理由で有効にする価値があります。
アプリは稼働中みずから収集役なので、ログイン時に起動しておくことが、再起動のたびに
履歴へ穴が空くのを防ぎます。

**Collection → Keep collecting when this app is closed** をオンにすると、
バックグラウンドのデーモンを install します。オンの間はアプリの tick が新しいデータを
見つけて何もしない（コール0）ので、二重消費は起きず、同期させる設定もありません。

オフのままだとアプリ終了中の記録は残りません。**SwitchBot API には履歴取得の
エンドポイントが無い**ので、後から API で埋めることはできず、SwitchBot アプリで
その期間をエクスポートして `sensor-lens import` するしかありません。History
ウィンドウは欠測区間を、線でつなぐのではなく欠測として描きます。

## CO2 アラート

CO2 はここで唯一「しきい値が行動に直結する」測定値なので、色を付けるのは CO2 だけです。
elevated（既定 1000 ppm）を超えるとバーに空気質のアイコンが出て、high（既定 1500 ppm）
を超えると赤くなります。通知も任意で出せます（測定のたびではなく、部屋ごとに
超過1回だけ）。

## API 消費

アカウントの上限は1日 10,000 コールで、超えても派手には失敗しません。API が
"Unauthorized" を返すようになるだけで、トークンが間違っている場合と区別がつきません。
Collection タブに本日の消費と現在の設定での見込みを表示しているのは、この数字が
「気づいたら謎の障害」になる前に見えるようにするためです。

## 開発

```bash
make build-app   # CLI 同梱の署名済み .app
make test        # swift test
make package     # notarize + staple + zip
```

先に CLI をビルドしてください（`../sensor-lens` で `make build`）。`build-app` が
署名済みバイナリを同梱します。構成と注意点は `AGENTS.md` を参照。
